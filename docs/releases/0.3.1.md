# Kodi Reader 0.3.1

Kodi Reader can now find and install updates from inside the app.

- Automatic daily update checks notify you when a new version is available.
- Choose **Kodi Reader → Check for Updates…**, or use the button on the home screen.
- The update window downloads, verifies, and installs the update, then relaunches Kodi Reader.
- **Settings → Updates** lets you control automatic checks and optionally enable
  automatic downloading and installation.
- Your books, notes, conversations, and reading progress stay on your Mac.

Updates and the update feed are signed. The app is signed with Developer ID and
notarized by Apple.

## Install this first update

Versions 0.3.0 and earlier do not include the updater. Download `KodiReader.dmg`,
quit Kodi Reader, and drag the app into Applications, choosing Replace. This is
the last manual install needed to enable future in-app updates.

Requires Apple Silicon and macOS 15 or later.
