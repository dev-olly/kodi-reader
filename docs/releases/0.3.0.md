# Kodi Reader 0.3.0

Read without losing your place when opening Notes or Ask AI, with quieter keyboard
navigation and a cleaner Notes sidebar.

## What's new

- Keyboard page navigation consumes handled keys correctly, preventing macOS alert sounds.
- EPUB passages stay on the same side of the spread and at the same height when the
  sidebar opens, resizes, or closes. Closing restores the original layout while keeping
  any pages you deliberately turned. Narrow windows use an overlay to preserve the text.
- A compact Notes/Ask AI switcher, a clearer Notes empty state, and less visual clutter.
- Email-code sign-in for Ask AI, with sessions stored in macOS Keychain. Questions and
  attached passages survive sign-in and temporary failures without being sent automatically.
- Sign-out and account deletion from the Ask AI account menu. Books, notes, and saved
  conversations remain on your Mac.

## Install

Requires **Apple Silicon and macOS 15 or later**.

Download `KodiReader.dmg`, quit the existing app, open the disk image, and drag
**Kodi Reader** into **Applications** to replace the previous version.

**Ask AI users must update to this version:** the accompanying API update requires
sign-in. Reading and notes remain available offline without an account.
