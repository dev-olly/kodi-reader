These are one-time, tax-inclusive EUR prices. Purchased credits do not expire. There is no subscription, automatic renewal, or automatic top-up. One credit pays for one Ask AI answer or follow-up.

The prices are approved for Paddle Live catalog creation and public product information. The €1 / €2 / €3 Paddle Sandbox prices remain test-only and must not be reused in Live.

## Cost decision

This pricing uses the measured normal-request estimate rather than the request-cap stress case. At the current measured normal average, model usage is approximately $1.15 / $2.75 / $6.42 for the three packs before payment fees, tax, refunds, welcome-credit subsidy, hosting, and support.

The existing four-request benchmark is small. If a substantial share of production answers approaches the 8,000-input / 2,048-output limits, these prices can be unprofitable. Monitor billed token cost per completed answer from launch and pause new checkout if the observed cost exceeds the launch budget. Existing purchased balances must continue to be honored.

Changing these retail prices requires a new owner decision and matching changes in Paddle, the backend pack map, the website, and customer-facing purchase information.
