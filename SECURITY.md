# Security

If you find a vulnerability in Kodi Reader, please do **not** open a public
issue.

Use [GitHub private vulnerability reporting](https://github.com/dev-olly/kodi-reader/security/advisories/new)
so the report stays private until a fix is out.

Please include the version (`0.1.0` or the git commit), macOS version, and
steps to reproduce. Secrets, API keys, and book contents should never be
attached to a public ticket.
