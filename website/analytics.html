Small signals. A clearer picture.About these metrics +

Account data and app telemetry measure different things. Registered accounts come from authentication records. AI accounts and requests come from credit reservations; charged requests can include responses interrupted after text was generated. Charged and refunded do not mean completed and failed.

Latest sign-in is a limited signal. The account metric counts users whose latest auth sign-in falls in the selected period. It is not a sign-in event history, daily active users, app sessions, or a measure of reading. New registrations and AI reservations have separate daily records.

Snapshots stay captured. A database snapshot shows aggregate records at its displayed capture time. Refreshing this view rereads the saved snapshot; it does not query the production database.

Devices, not identified people. Kodi sends a random installation identifier. Reinstalls and multiple devices can count as more than one device; the telemetry installation ID is not linked to an email or Kodi account.

Reader engagement includes the workspace. The shared clock includes reading, notes, drawing, and Ask AI in the foreground reader workspace. It pauses when hidden, minimized, asleep, outside that workspace, or idle for two minutes. It measures engagement, not attention or pure reading time.

Meaningful feature counts. A new note or drawing counts once. Subsequent changed editing sessions count separately; autosaves, sync restores, empty drafts, and failed saves are excluded. Legacy autosaves remain labeled separately.

Approximate connection countries. Country comes from the upload connection. Each active installation counts once under its latest available observation in the selected period. Missing observations are Unknown; delayed uploads do not reconstruct the location of offline activity.

AI outcomes follow request starts. New requests use a telemetry-only random request ID, separate from account and billing identifiers. The outcomes belong to requests started in the selected period; in-flight, interrupted, and uncorrelated legacy requests remain Unknown.

A consistent window. Dates use UTC. Changes compare the selected period with the same elapsed span immediately before it. Reader engagement and feature usage before app telemetry shipped are unavailable.

Only usage signals. No book titles, text, prompts, AI responses, notes, sketches, or visited URLs are sent to this dashboard. Device telemetry excludes installations that opt out. Server account and credit records are measured independently.
