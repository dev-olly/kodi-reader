# Kodi Reader 0.2.0

Kodi Reader now opens PDFs alongside EPUBs and has a new forest-green app icon.
This release is signed with Developer ID and notarized by Apple.

## What's new

- Native PDF reading with fit-to-page zoom, adaptive two-page spreads, and section navigation.
- PDF highlights, notes, drawings, and passage context for Ask AI.
- Saved PDF reading positions and durable library imports alongside EPUBs.
- New logo across the app, welcome screen, and website.
- Signed, notarized macOS download with Apple's notarization ticket attached.

## Install

Requires **Apple Silicon and macOS 15 or later**.

Download `KodiReader.dmg`, open it, and drag **Kodi Reader** into **Applications**.
If updating, quit the existing app before replacing it. macOS may display its
normal first-open confirmation for an app downloaded from the Internet.

## Verification

The release passed all 135 Swift package tests and the note-editor checks.
The DMG is verified for its Developer ID signature, stapled notarization ticket,
and Gatekeeper acceptance before publication.
